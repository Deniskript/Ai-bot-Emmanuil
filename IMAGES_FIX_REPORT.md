**Файл:** `web_app.py` (строки 465-472)

**Реализация:**  
Добавлен новый роут `/images/settings` который отображает страницу настроек генерации изображений.

**Код:**
```python
@app.route('/images/settings')
def images_settings():
    """Telegram Mini App - Настройки генерации изображений"""
    try:
        return render_template('images_settings.html')
    except Exception as e:
        print(f"Error loading images settings: {e}")
        return f"Error: {e}", 500
```

Роут доступен по адресу `https://soul-bot.ru/images/settings` и корректно отображает страницу настроек.
