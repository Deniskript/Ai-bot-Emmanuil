## 📋 Описание

Luca (Soul AI) - интеллектуальный друг и помощник с долгой памятью и двумя режимами общения.

### 🎯 Основные возможности

- **🕊️ Режим "Душа"** - для душевных разговоров, поддержки, вдохновения
- **💡 Режим "Разум"** - для задач, решений, структурированной работы
- **🎤 Голосовой режим** - общение голосовыми сообщениями
- **🧠 Долгая память** - запоминает до 15 фактов о пользователе
- **📖 Telegraph** - публикация длинных ответов
- **🌐 Web интерфейс** - настройки и помощь через браузер

## 🔌 Подключение модуля

### 1. В `main.py`:

```python
from handlers import luca

# Подключить Telegram handlers
dp.include_router(luca.router)

# Подключить web интерфейс (опционально)
if luca.WEB_AVAILABLE:
    app.add_subapp('/luca', luca.web_router)
```

### 2. Готово! Модуль работает
